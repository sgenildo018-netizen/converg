FastAPI: Implementação de Rota Coringa com Wildcard Path e Middleware de Telemetria

Guia de referência arquitetural para captura dinâmica de rotas legadas com validação via Pydantic v2 e instrumentação Prometheus nativa em topologias assíncronas.

FastAPI Python 3.12 Docker Engine Production Ready speedLatency: ~1.2ms
Atualizado há 14m por @alex.eng • 4 min de leitura • 1.420 palavras
warning

Atenção Crítica de Performance & Roteamento

Rotas coringa ({full_path:path}) devem ser sempre registradas por último na instância principal da FastAPI ou no respectivo APIRouter. Inseri-las antes causa path shadowing e sequestra requisições de endpoints estáticos declarados subsequentemente.

SECTION 01

1. Arquitetura da Solução & Definição de Path

A migração gradual de microsserviços legados (como monolitos Django ou Express) para arquiteturas assíncronas modernas exige um mecanismo tolerante a rotas não catalogadas. O FastAPI emprega internamente o parser do Starlette, suportando conversores de tipo específicos onde o prefixo :path indica que qualquer caractere de barra (/) deve ser mantido na string final ao invés de atuar como delimitador de segmento.

code app/routers/fallback.py Python 3.12
Copiado! 
from fastAPI import APIRouter, Request, status, HTTPException
from starlette.responses import JSONResponse
import structlog

router = APIRouter(prefix="/api/v1")
logger = structlog.get_logger()

@router.get("/{full_path:path}", tags=["Dynamic Fallback"])
async def dynamic_route_handler(full_path: str, request: Request):
    request_id = request.headers.get("X-Request-ID", "unknown")
    logger.info("fallback_route_hit", path=full_path, req_id=request_id)

    if full_path.startswith("internal/"):
        raise HTTPException(
            status_code=status.HTTP_403_FORBIDDEN,
            detail="Acesso restrito ao subsistema confidencial."
        )

    return JSONResponse(content={
        "status": "routed",
        "resolved_path": full_path,
        "cache_hit": True
    })

Ao declarar o parâmetro da função como full_path: str, o interpretador injeta todo o sufixo pós-/api/v1/, viabilizando o desacoplamento de pipelines legadas sem a necessidade de reconfigurar o gateway upstream do Kubernetes Ingress.

SECTION 02

2. Middleware ASGI Customizado para Telemetria

Capturar o ciclo de vida completo requer interceptação na camada ASGI via BaseHTTPMiddleware. Armazenamos cronometragens em request.state.time_elapsed e alimentamos métricas Prometheus diretamente:

tune app/middlewares/telemetry.py Prometheus ASGI 
import time
from starlette.middleware.base import BaseHTTPMiddleware
from prometheus_client import Histogram, Counter

HTTP_REQUEST_LATENCY = Histogram(
    'fastapi_request_duration_seconds',
    'Tempo de latência por endpoint',
    ['method', 'endpoint', 'http_status']
)

class TelemetryMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request, call_next):
        start_time = time.perf_counter()
        response = await call_next(request)
        latency = time.perf_counter() - start_time

        request.state.time_elapsed = latency
        response.headers["X-Process-Time"] = f"{latency * 1000:.2f}ms"

        HTTP_REQUEST_LATENCY.labels(
            method=request.method,
            endpoint=request.url.path,
            http_status=response.status_code
        ).observe(latency)

        return response
